Screenwriting on Linux

Cold Open is a free, open-source screenwriting app that runs natively on Linux: the same app, and the same page breaks, as on Windows and macOS. It opens and saves .fdx files, so you can exchange scripts with writers and producers who use Final Draft, which doesn't run on Linux.

Download for Linux

Three ways to install it

  • AppImage: one file that runs on any distribution, without installing. chmod +x it and run it.
  • .deb: for Debian, Ubuntu, Mint and Pop!_OS, with a menu entry and file types. sudo apt install ./cold-open_*_amd64.deb
  • Flatpak: for any distribution with Flatpak.

Each comes for x86-64 and ARM64, and is under 15 MB. Cold Open needs glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36 and later), and runs on Wayland and X11. Install has the details.

Made for it, not ported to it

  • Native code, written in Rust, with its own fonts bundled, so a script lays out the same on every computer whatever fonts you have.
  • Plain files. Fountain, Cold Open's own format, is plain text: it works with git, diff and any editor.
  • A command line. coldopen export script.fountain script.pdf, coldopen convert draft.fdx draft.fountain, coldopen diff a.fdx b.fdx: batch work without opening the app.
  • Free software: the app is under the GPL-3.0-or-later, and its format and layout libraries under MIT or Apache-2.0.

Everything a script needs

Standard screenplay format with smart element flow, autocomplete for names and places, track changes, production revision colors, a title page editor, reports, PDF export, and a crash journal that means a crash never costs you what you typed.

Cold Open is in alpha: careful with your work, but new. Keep copies of anything that matters, and tell us how it runs on your distribution.
