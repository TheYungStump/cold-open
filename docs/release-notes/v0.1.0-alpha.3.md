The third alpha of Cold Open: a free, open-source screenwriting app that reads and writes Fountain and .fdx files, paginates the same on every computer, and journals every keystroke, so a crash costs nothing.

**This is an alpha.** Keep copies of anything that matters. Your scripts are plain Fountain and .fdx files, so nothing you write here is locked in.

**New here?** The website has everything: [downloads](https://theyungstump.github.io/cold-open/download/), the [user guide](https://theyungstump.github.io/cold-open/guide/), and the [tester guide](https://theyungstump.github.io/cold-open/alpha/tester-guide.html), a 20-minute tour.

## What's new since alpha.2

- **One download for every Mac.** The universal disk image runs on Apple chips and Intel alike, and fits the 15 MB budget. The per-chip images are still there, a little smaller.
- **Settings** (Ctrl+Comma, or Cmd+Comma on a Mac, where it's also Cold Open ▸ Settings…): the theme, interface size, renderer, your name on tracked changes, agent access, crash reports and the usage summary, in one sheet you can use from the keyboard alone.
- **Share feedback…** (palette, About, start screen): type what you think and open our form or a GitHub issue with it filled in. Nothing is sent until you submit it yourself.
- **A usage summary, on your computer only.** Cold Open counts which features you use, so feedback can say what you rely on. It holds counts, never your text, names or file paths, and Cold Open never sends it: it goes out only if you tick **Include my usage summary** when you share feedback, and you see all of it first. Settings shows it in full, resets it, or turns counting off. See [what it holds](https://theyungstump.github.io/cold-open/guide/settings.html#the-usage-summary).
- **Saving an .fdx file on a Mac no longer holds the app up for a few milliseconds.** After each save Cold Open flushed the drive once more than it needed to, and the next save could wait for it.
- **The new icon,** in the project's final brand.
- **For AI clients:** `ColdOpen-0.1.0-alpha.3-mcp.mcpb` holds Cold Open's MCP server for clients that install MCP bundles.
- The full list is in the [changelog](https://github.com/TheYungStump/cold-open/blob/main/CHANGELOG.md).

| --- | --- |
| Windows 10 or 11 (most PCs) | `ColdOpen-0.1.0-alpha.3-windows-x64-setup.exe` |
| Windows on ARM (Surface Pro X, Snapdragon laptops) | `ColdOpen-0.1.0-alpha.3-windows-arm64-setup.exe` |

## The first start

These builds aren't signed by Microsoft or notarized by Apple yet, so your system warns you the first time.

- **Windows:** SmartScreen may say "Windows protected your PC". Click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **macOS:** open the `.dmg` and drag Cold Open to Applications. The first time you open it, macOS refuses. Open **System Settings ▸ Privacy & Security**, scroll down to the message about Cold Open, and click **Open Anyway**. On macOS 12 to 14 you can also Control-click the app and choose **Open**. If macOS says the app is damaged, run this in Terminal, then try again:

  ```
  xattr -dr com.apple.quarantine "/Applications/Cold Open.app"
  ```
- **Linux:** `sudo apt install ./cold-open_*.deb`; or `chmod +x ColdOpen-*.AppImage` and run it; or `flatpak install --user ColdOpen-*.flatpak`. The Flatpak can open scripts in your home folder. For another drive, run `flatpak override --user --filesystem=/path/to/drive io.github.theyungstump.coldopen`.

## The command-line tool

`coldopen` converts, exports, compares and repairs scripts, and runs an MCP server for AI agents (`coldopen mcp`).

- **Windows installer:** it's on your PATH. Open a new terminal.
- **macOS:** choose **Install the command-line tool** in the palette (Cmd+K).
- **.deb:** `/usr/bin/coldopen`.
- **AppImage:** `./ColdOpen-*.AppImage cli --help`.
- **Flatpak:** `flatpak run --command=coldopen io.github.theyungstump.coldopen`.

Please send them to us, especially from a Mac or Linux.

Please never attach a script you don't own. A short scene of your own that shows the problem is best.

## Known issues

- **macOS:** double-clicking a `.fountain`, `.fdx` or `.coldopen` file starts Cold Open but doesn't open the file yet. Use Open (Cmd+O) instead.
- **Windows:** Cold Open appears in "Open with" for `.fountain` and `.fdx` files. Windows lets only you make it the default.
- The rest are in [Known limitations](https://theyungstump.github.io/cold-open/guide/limitations.html).
