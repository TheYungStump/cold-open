The second alpha of Cold Open, and the first we're inviting testers to: a free, open-source screenwriting app that reads and writes Fountain and .fdx files, paginates the same on every computer, and journals every keystroke, so a crash costs nothing.

**This is an alpha.** Keep copies of anything that matters. Your scripts are plain Fountain and .fdx files, so nothing you write here is locked in.

**New here?** The website has everything: the [user guide](https://theyungstump.github.io/cold-open/guide/), the [install notes](https://theyungstump.github.io/cold-open/guide/install.html), and the [tester guide](https://theyungstump.github.io/cold-open/alpha/tester-guide.html), a 20-minute tour.

## What's new since alpha.1

- **Report a problem…** in the palette, in About, and on the start screen. It opens a ready-filled GitHub issue in your browser, or our feedback form if you don't have a GitHub account, with Cold Open's version, your system and the renderer, and nothing from your script. Nothing is sent until you submit it yourself.
- **Crash reports, if you want them.**
  - If Cold Open crashes, it saves a short report on your computer, holding no script text, file names or user names.
  - At the next start it offers to show you the report, and you can send it, or not.
  - **Never ask again** turns reports off.
- **Crash on purpose (to test recovery)** in the palette closes Cold Open as a crash would, so you can see your work come back.
- **The user guide and website**, with a keyboard, command-line and command reference made from Cold Open's own code.
- **Open the user guide** in the palette and About.
- **Every command's parameters are described**, for agents and in the reference.
- **The command-line tool's file details** name Cold Open and the version on Windows.
- The full list is in the [changelog](https://github.com/TheYungStump/cold-open/blob/main/CHANGELOG.md).

## The first start

These builds aren't signed by Microsoft or notarized by Apple yet, so your system warns you the first time.

- **Windows:** SmartScreen may say "Windows protected your PC". Click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **macOS:** open the `.dmg` and drag Cold Open to Applications. The first time you open it, macOS refuses. Open **System Settings ▸ Privacy & Security**, scroll down to the message about Cold Open, and click **Open Anyway**. On macOS 12 to 14 you can also Control-click the app and choose **Open**. If macOS says the app is damaged, run this in Terminal, then try again:

  ```
  xattr -dr com.apple.quarantine "/Applications/Cold Open.app"
  ```
- **Linux:** `sudo apt install ./cold-open_*.deb`; or `chmod +x ColdOpen-*.AppImage` and run it; or `flatpak install --user ColdOpen-*.flatpak`. The Flatpak can open scripts in your home folder. For another drive, run `flatpak override --user --filesystem=/path/to/drive io.github.theyungstump.coldopen`.

## The command-line tool

`coldopen` converts, exports, compares and repairs scripts, and runs an MCP server for AI agents (`coldopen mcp`).

- **Windows installer:** it's on your PATH. Open a new terminal.
- **macOS:** choose **Install the command-line tool** in the palette (Cmd+K).
- **.deb:** `/usr/bin/coldopen`.
- **AppImage:** `./ColdOpen-*.AppImage cli --help`.
- **Flatpak:** `flatpak run --command=coldopen io.github.theyungstump.coldopen` (or add `alias coldopen='flatpak run --command=coldopen io.github.theyungstump.coldopen'` to your shell).

- **Report a problem…** in the app, or a [GitHub issue](https://github.com/TheYungStump/cold-open/issues/new/choose).
- [Discussions](https://github.com/TheYungStump/cold-open/discussions) for how testing went, questions and ideas.

**Help us measure it:** choose **Measure performance** in the palette, or run `coldopen bench`. It takes about two minutes and writes two small files to your Downloads folder, holding your computer's model names and the times, and nothing else. Please send them to us, especially from a Mac or Linux.

Please never attach a script you don't own. A short scene of your own that shows the problem is best.

## Known issues

- **macOS:** double-clicking a `.fountain`, `.fdx` or `.coldopen` file starts Cold Open but doesn't open the file yet. Use Open (Cmd+O) instead.
- **Windows:** Cold Open appears in "Open with" for `.fountain` and `.fdx` files. Windows lets only you make it the default.
- The app's icon is a stand-in.
- The rest are in [Known limitations](https://theyungstump.github.io/cold-open/guide/limitations.html).
