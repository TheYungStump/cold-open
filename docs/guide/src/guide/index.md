# About this guide

This guide is for writers. It says how to install Cold Open, write a first scene, and use each feature, in the order you're likely to meet them.

- **New to Cold Open?** Start with [Install](install.md), then [Getting started](getting-started.md).
- **New to Fountain?** [A Fountain primer](fountain.md) takes five minutes.
- **Working with a production?** See [.fdx exchange](fdx.md), [Track changes](track-changes.md), [Production revisions](revisions.md) and [Compare drafts](compare.md).
- **Worried about losing work?** [Your work is safe](recovery.md) explains the crash journal.
- **Using an AI agent?** See [AI agents](agents.md).
- **Looking for a key or a command?** The [keyboard](../reference/keyboard.md), [command-line](../reference/cli.md) and [command](../reference/commands.md) references list every one. They're made from Cold Open's own code, so they match the version they came with.

Two things are worth knowing from the start:

- **The command palette** (Ctrl+K, or Cmd+K on a Mac) lists everything Cold Open can do, with its keys. If you can't find something, type a word of it there.
- **This is an alpha.** [Known limitations](limitations.md) lists what isn't there yet. Keep copies of scripts that matter.

In this guide, **Mod** means Ctrl on Windows and Linux, and Cmd on a Mac. So Mod+S is Ctrl+S or Cmd+S.
